# ИЗОБОНД — прототип нового сайта

Интерактивный прототип нового сайта производителя рулонных изоляционных материалов **ИЗОБОНД** (ТМ ООО ТД «Ван Маркет»).

## 🔗 Открыть прототип

**→ https://expresstilda.github.io/izobond-site-prototype/**

## Что это

Кликабельный прототип многостраничного сайта (14 страниц) — не изображение, а рабочий интерактив: навигация между страницами, подбор материала, калькулятор, фильтры каталога, переключение светлой/тёмной темы.

### Страницы
- **Главная** — витрина с ключевыми преимуществами
- **Продукция** — каталог с фильтрами по назначению, типу и наличию
- **Карточка товара** — характеристики, цена, сопутствующие товары
- **Подбор материала** — выбор по узлу конструкции
- **Калькулятор** — расчёт количества рулонов
- **Применение** — сценарии использования
- **Где купить** — сети, маркетплейсы, дилеры, опт
- **Дилерам** — условия партнёрства и заявка
- **О компании**, **Доставка и оплата**, **Новости и акции**, **Полезное**, **Контакты**, **Вакансии**

## Статус

Это **дизайн-прототип** для согласования. Формы и часть данных (фото, сертификаты, карта дилеров, цены) — заглушки; помечены в интерфейсе. Заявки не отправляются.

## Формы заявки — 19 октября 2026

- «Получить прайс» в шапке открывает форму запроса прайса на e-mail.
- «Запросить опт» в карточке товара открывает форму с выбранным товаром и артикулом.
- «Получить расчёт и цену» в калькуляторе открывает форму со всеми параметрами и результатом расчёта. «Изменить расчёт» возвращает к исходным данным.

Есть мобильная версия, светлая/тёмная тема, проверка полей, согласие, состояния отправки и успеха. Внизу каждой формы раскрывается «Просмотр состояний для дизайнера»: ошибки полей, ошибка отправки, успешная отправка.

Отправка демонстрационная: данные не передаются и не сохраняются. Ссылки на согласие и политику открывают явно обозначенные макеты документов; согласованные тексты и обработчик заявок нужно подключить при разработке сайта.

Исходники форм: `lead-forms.js` и `lead-forms.css`. Для локального просмотра достаточно открыть `index.html` в браузере.
